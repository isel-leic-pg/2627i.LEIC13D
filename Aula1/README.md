# Aula 1 — Introdução

Exemplos para acompanhar a Aula 1: escrever, compilar e executar um programa; escrita no ecrã.

| Ficheiro | Demonstra |
|---|---|
| `ola.kt` | O primeiro programa: `println` |
| `print_vs_println.kt` | Diferença entre `print` e `println` |

## Como correr
Compilar com `kotlinc` e depois executar com `kotlin`. O nome da classe é o do
ficheiro com a **1.ª letra em maiúscula** e `Kt` no fim (sensível a maiúsculas):

```
kotlinc ola.kt
kotlin OlaKt

kotlinc print_vs_println.kt
kotlin Print_vs_printlnKt
```
